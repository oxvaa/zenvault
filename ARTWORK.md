# Ink Collection — artwork sources

Created with the built-in imagegen tool. Reference: user-provided Clipper photo, used only for visual style. Original Zenvault illustrations; no Clipper branding or lighter imagery is included in the app.

Project assets: assets/cards/cyan.jpg, lime.jpg, pink.jpg, orange.jpg. CardArtAssets.js loads the actual files with static require calls. Snack publishes all illustration files as ASSET entries, with native image metadata; the renderer also supplies explicit measured width and height. Delivery copies are resized to 1000 px wide and JPEG encoded for mobile memory and Snack payload size. Full generated PNG sources remain in the generated_images workspace directory.
